How-to guides
=============

These guides apply scim2-flask to a task whose outcome is already known. Each one starts and ends
where an application resumes its own work, and assumes the :doc:`../tutorial`.

The examples reuse ``InMemoryStorage`` and ``create_provider`` from the tutorial. Replace them
with your own storage and provider.
